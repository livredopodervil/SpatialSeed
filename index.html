Manual breve

Um primeiro percurso em quatro movimentos.

  1. 1

    Abra o editor

    Use a barra para criar uma geometria ou o painel Explorar para gerar uma construção declarativa.

  2. 2

    Selecione e transforme

    Escolha seleção única ou múltipla. Mova, gire ou escale; a alça branca central aplica escala proporcional nos três eixos.

  3. 3

    Programe pela mesma via

    Abra o console e consulte help. Comandos, procedimentos e Inspector convergem nos mesmos contratos editoriais.

  4. 4

    Teste antes de conservar

    Use runtime test all, revise a cena e salve um arquivo .spatialseed quando quiser torná-la portátil.
